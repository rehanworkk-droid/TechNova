# MERN Stack eCommerce Website

A full-stack eCommerce web application built with the **MERN Stack (MongoDB, Express.js, React.js, and Node.js)**. The application provides a modern online shopping experience with secure authentication, product management, shopping cart functionality, and an admin dashboard.

## Features

* Secure authentication and authorization using **Auth0**
* Role-based access for **Admin** and **Customer**
* Browse, search, and filter products
* Shopping cart and wishlist functionality
* Order management for customers
* Admin dashboard to manage products, categories, users, and orders
* RESTful API integration
* Responsive design for desktop and mobile devices

## Tech Stack

* **Frontend:** React.js
* **Backend:** Node.js, Express.js
* **Database:** MongoDB
* **Authentication:** Auth0
* **API:** RESTful APIs

## Purpose

This project was developed to strengthen full-stack development skills by building a scalable eCommerce platform with modern web technologies and industry-standard authentication practices.
